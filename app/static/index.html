What runs locally

Whisper recognizes Japanese speech and timestamps. Ollama / NLLB translates to Tamil. IndicF5 generates Tamil speech from a reference voice. FFmpeg places it into the original video.

Before you start

First run downloads model weights and can take time. An NVIDIA GPU is strongly recommended. CPU mode works in supported environments but can be slow. This is a local app, not a hosted cloud service or a 25-minute free cloud credit.

Voice cloning tip

For the cleanest Tamil pronunciation, upload a 10–15 second Tamil voice sample with its exact transcript. Extracting a Japanese sample is supported but cross-lingual quality varies by voice and scene noise.
